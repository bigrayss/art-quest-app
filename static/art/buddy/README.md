# 彩点的立绘

用户 2026-10-03 给的素材。界面里**九处**彩点全部用它（`paintBuddy()` / `buddyHtml()`）：
门口 · 顶栏小头像 · 过程条 · 「彩点的世界」大图 · 画画屏右栏 · 支招页 · 问卷页 · 对比页 ·
地图上「你在这儿」和「今天」卡。

## 两层：身体 + 颜料

| 文件 | 是什么 |
| --- | --- |
| `hero.webp` / `hero-paint.webp` | 大图（560px）。门口和「彩点的世界」用 |
| `icon.webp` / `icon-happy.webp` / `icon-paint.webp` | 小图标（256px）。其余七处用 |

`*-paint` 是**纯白剪影**，用 CSS `mask-image` 染成孩子当前用的颜色（`buddyColor()`）。
所以「彩点是一坨会变色的颜料精灵」这条设定还在，只是**颜色从整个身体挪到了身上那几点颜料**：
还没画过 → 颜料是灰的；画出颜色 → 颜料亮成那个颜色。身后那圈光仍然跟着同一个颜色。

图加载不出来时 `onerror` 把容器标成 `data-noart`，CSS 换回 `spriteInner()` 画的 SVG 线稿——
和 families/badges「有图用图、没图用线稿」一个路子，**别把那条兜底删掉**。

`hero` 和 `hero-paint` 进了 `sw.js` 的 `SHELL_URLS` 和 `main.py` 的 `_SHELL_FILES`（首屏要用，
缓存优先；换图自动 bump 外壳版本）。小图标走 ASSETS 缓存，懒加载。

## 素材来源（2026-10-04 换过一次）

现在这套全部从 **`docs/橙色贝雷帽的开心小画家.png`**（1312×1199，真·透明底）出，
脚本 `tmp/mkbuddy.py`，一条命令重出全部四个文件。用户原话：「這個圖片素材作爲主要的初始精靈」。

**上一版（`彩绘冒险_精灵分层8文件.zip`）已经不用了**，它交来时大图有三个毛病：
又烤进了手写的 "Let's Create!"、擦颜料留了亮斑和一滴没擦净的蓝、还烤了一层淡白底
（压在暖纸上会透出一个方框，用户看线上第一眼就是「爲啥小精靈背景有顏色」）。

### 两层是怎么拆出来的
原图的颜料点是画死在身上的，所以拆层这件事是脚本干的，不是美术给的：

- **颜料剪影**：身上那五点的位置量出来在 `x 439–566, y 595–852` 这个框里
  （贝雷帽在上面、**铅笔右缘在 x 425–438**、脸蛋在右边，都在框外）。框里按饱和度取，
  再把零星小块（铅笔边缘的毛刺）按连通块扔掉。
  ⚠️ **铅笔和最左那点颜料只差 1 px**，x0 定在 439 是量出来的，别随手改。
- **身体**：拿剪影当修补范围，在 190px 的缩略图上「反复模糊 + 把已知像素贴回去」扩散填充，
  再放大贴回原图——身体是一片平滑渐变，这样补完看不出来。

### 四个文件
| 文件 | 从哪儿裁 |
| --- | --- |
| `hero.webp` / `hero-paint.webp` | 整只，560px。门口和「彩点的世界」用 |
| `icon.webp` / `icon-paint.webp` | **只裁贝雷帽和圆身子**（385,145,1075,962），256px。其余八处用 |

小图标为什么要另裁：整只直接缩到 40–62px，铅笔和手脚会糊成一团（比过，很明显）。

**`icon-happy.webp` 现在就是 `icon.webp` 的副本**——新角色本来就是笑脸，手上只有这一个表情。
原来「该笑的地方换成开心脸」那条暂时等于没生效。要恢复，需要用户再给一张**同一角色的大笑/眨眼版**。

## 门口没有光晕

原来彩点身后垫了一层橙黄的柔光。换成干净的透明 PNG 之后它就是平白多出来的一块颜色，
用户 2026-10-04：「首頁爲啥小精靈背景有顏色」。已经 `display:none`。
**「彩点的世界」那一屏的光还留着**——那一圈的亮度是九维进度，有意义，别一起删。
