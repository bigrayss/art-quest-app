# 彩点的立绘

用户 2026-10-03 给的素材。界面里**九处**彩点全部用它（`paintBuddy()` / `buddyHtml()`）：
门口 · 顶栏小头像 · 过程条 · 「彩点的世界」大图 · 画画屏右栏 · 支招页 · 问卷页 · 对比页 ·
地图上「你在这儿」和「今天」卡。

## 两层：身体 + 颜料

| 文件 | 是什么 |
| --- | --- |
| `hero.webp` / `hero-paint.webp` | 大图（560px）。门口和「彩点的世界」用 |
| `icon.webp` / `icon-happy.webp` / `icon-paint.webp` | 小图标（256px）。其余七处用 |

`*-paint` 是**纯白剪影**，用 CSS `mask-image` 染成孩子当前用的颜色（`buddyColor()`）。
所以「彩点是一坨会变色的颜料精灵」这条设定还在，只是**颜色从整个身体挪到了身上那几点颜料**：
还没画过 → 颜料是灰的；画出颜色 → 颜料亮成那个颜色。身后那圈光仍然跟着同一个颜色。

图加载不出来时 `onerror` 把容器标成 `data-noart`，CSS 换回 `spriteInner()` 画的 SVG 线稿——
和 families/badges「有图用图、没图用线稿」一个路子，**别把那条兜底删掉**。

`hero` 和 `hero-paint` 进了 `sw.js` 的 `SHELL_URLS` 和 `main.py` 的 `_SHELL_FILES`（首屏要用，
缓存优先；换图自动 bump 外壳版本）。小图标走 ASSETS 缓存，懒加载。

## 原始素材做过什么处理（`docs/彩绘冒险_精灵分层8文件.zip`）

小图标四张**原样可用**。大图那两张交来时有三个毛病，脚本在 `tmp/fixart.py`：

1. **左上角又出现了手写的 "Let's Create!"**（还被裁成 "et's Create!"）。逐行擦到贝雷帽左缘
   往左 14px，边缘羽化，不留直边——不能整块裁掉，铅笔就在那下面。
2. **擦颜料留了残影**：身上一块块比周围亮的斑，左下角还有一滴蓝色没擦净。拿 paint 剪影
   当修补范围（再加上按饱和度找出来的漏网彩色像素），在缩略图上做扩散填充再放大贴回去。
3. **烤了一层很淡的白底**，压在暖纸上会透出一个方框。alpha ≤14 整个抹掉、14–46 收一档，
   角色的软阴影和地上的蜡笔痕（都 ≥46）原样留着。

## ⚠️ 还缺一张：大图的开心表情

`large_happy_body.png` **脸是坏的**：笑脸直接盖在原脸上，原来那只右眼还露在外面，
盖上去的那块有明显的灰色晕边，还多了一颗橘红色的点。没用它。

所以现在「彩点的世界」那张大图只有常态一种表情——原来的规则是九维全点亮（`total_level >= 9`）
时换成开心脸，这条暂时按常态走。**要恢复它，需要用户重出一版 `large_happy_body.png`**
（1120×1120，和 `large_normal_body.png` 像素对齐，只改眼睛和嘴）。
小图标的开心脸是好的，其余七处该笑的时候都在笑。

zip 里第一批 16 张（`彩绘冒险_精灵分图.zip`）的其余姿势还没用上：挥手、眨眼、欢呼、困惑、
爱心、平静、旗子、放大镜、速写本、背面、侧面，以及三张场景图。其中 7 张把中文说明烤进了图里。
