# 彩绘冒险 · 第一次试点

**2026-10-01 · 学校机房，电脑网页版 · https://art.ddhulu.cn**

目的：看孩子在电脑上能不能顺利玩下来，一节课能玩几关。鼓励每个孩子尽量把地图上的每一关都玩一遍。

## 课前一天

每台电脑逐一检查：

1. 浏览器 Chrome 或 Edge。
2. 打开 https://art.ddhulu.cn 能看到门口，点「跳过」能进地图。
3. 浏览器缩放 100%（Ctrl+0），桌面放一个网址快捷方式。
4. 机房如果拦网址，请信息老师把 `art.ddhulu.cn` 加白名单。
5. 自己试画一关，确认能画完。

服务器用默认设置就行，不用改。

名册一张纸：每个孩子一个代号（如 `A07`）和一个四位数密码。课后老师收走，代号和真名的对照不进电脑。

## 上课（40 分钟）

| 时间 | 事 |
|---|---|
| 0–3 分 | 开场：这是个画画游戏，地图上有十关，每关一个题，尽量都玩一遍。画什么、画得像不像都可以，没有分数。 |
| 3–8 分 | 每人打开网址 → 注册：名字填代号，密码填纸上那个 → 看完导览 → 到地图 |
| 8–38 分 | 自由玩。点亮的关都能进，一关画完回地图接着下一关。画完一关软件会说几句话，想改就改，不想改就下一关。 |
| 38–40 分 | 收尾。没画完的那关不用管，下次登录还在。 |

大人只帮找按钮，不帮画，不评价。孩子问「画这个行吗」，答「行」。

## 课后

```
ssh artquest
ls ~/artquest/data/sessions | wc -l                 # 大约 = 人数 × 平均玩的关数
rsync -az artquest:artquest/data/ ~/artquest-backup/pilot1-$(date +%F)/
```

## 要记的

- 全班登录完用了几分钟。
- 每个孩子玩了几关。服务器上按账号数。
- 哪一步有人卡住、卡在哪。
- 有没有人问「这是什么意思」，问的是哪句话。
- 下课时有没有孩子不想停。
