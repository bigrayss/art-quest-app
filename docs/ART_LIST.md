# 美术清单

要自己画的三样东西：**参考图**、**地图上十个地方的字形**、**徽章**，外加 app 图标。现在这些全是代码里临时生成的占位。每一项写了：放哪个文件、多大、画什么、孩子拿它干什么。**编号可以直接拿来指**：`1.5` 就是第 1 节第 5 项。

> 这份文件由 `tools/gen_art_list.py` 从代码里生成（徽章的名字和条件直接抽自 app.js）。**别手改**，改了下次生成会被覆盖；要改描述改脚本里的 DESC / STIM / GLYPHS。

**通用要求**：sRGB；PNG（要透明底的地方）或 JPG（照片）；不要任何文字、商标、真人的脸；内容适合 8–14 岁；来源是自己拍 / 自己画 / CC0，因为它们会随 app 发布。iPad 是 2× 屏，所有像素尺寸都已经按 2× 给出，**按这个尺寸交，不用再放大**。

## 2. 地图字形 · 10 枚 🟢 可换

地图上的十个「地方」，每个家族一枚。孩子还没去过的地方显示这枚字形；去过之后那个圆里换成他自己画的最近一张，所以字形是**第一眼的样子**。同一枚还出现在画廊卡片的标题前（很小）。

**尺寸与格式**（两种交法，选一种）

| 交法 | 要求 | 效果 |
| --- | --- | --- |
| A. 单色线稿 SVG（**推荐**，和现在一致） | `viewBox 0 0 24 24`，只描边不填色（最多一两个小实心点），描边 2.2、圆端点圆折角，颜色不写死（`currentColor`） | 代码给它上家族色；同一枚在 34 px 和 14 px 两个大小下都清楚 |
| B. 彩色插画 PNG | **228 × 228 px**，透明底，主体占 70 %，圆形构图（它装在一个圆里） | 我改代码用 `<img>` 显示；画廊里那个 14 px 的小标记仍用现在的线稿 |

**显示位置与大小**：地图圆钮 76 × 76 CSS px（2× 屏上 152 × 152 物理像素），字形 34 px；「下一关」那个圆有光晕和彩点趴在旁边；画廊卡片标题前 14 px。

## 3. 徽章 · 51 枚 🟢 可换

一枚章 = 一块带颜色的圆盘 + 上面一枚图形 + 底下名字。圆盘和名字是代码画的，**要画的只是圆盘上那枚图形**。徽章**只奖励过程**（画了多久、换了几种颜色、擦了多少），不奖励画得好不好，这是底线，图形上别出现「棒」「第一」这类意思。

**尺寸与格式**（和字形一样两种交法）

| 交法 | 要求 |
| --- | --- |
| A. 单色线稿 SVG（推荐） | `viewBox 0 0 24 24`，描边 2.2、圆端点，`currentColor`。代码把它印在组色的圆盘上，图形本身是白色 |
