# 美术清单

要自己画的三样东西：**参考图**、**地图上十个地方的字形**、**徽章**，外加 app 图标。现在这些全是代码里临时生成的占位。每一项写了：放哪个文件、多大、画什么、孩子拿它干什么。**编号可以直接拿来指**：`1.5` 就是第 1 节第 5 项。

> 这份文件由 `tools/gen_art_list.py` 从代码里生成（徽章的名字和条件直接抽自 app.js）。**别手改**，改了下次生成会被覆盖；要改描述改脚本里的 DESC / STIM / GLYPHS。

**通用要求**：sRGB；PNG（要透明底的地方）或 JPG（照片）；不要任何文字、商标、真人的脸；内容适合 8–14 岁；来源是自己拍 / 自己画 / CC0，因为它们会随 app 发布。iPad 是 2× 屏，所有像素尺寸都已经按 2× 给出，**按这个尺寸交，不用再放大**。

## 0. 风格：61 张要像一套

字形和徽章都走**彩色插画**（定了）。插画只要不是一套，墙上一眼就散。所以先定这几条，每一张都照着：

| 项 | 定法 |
| --- | --- |
| 世界 | **颜料和画具的世界**。彩点是一坨会变色的颜料精灵，所有东西都可以想成「被颜料弄脏的、软软的」——一把橡皮是一块软糖，一个时钟像捏出来的黏土 |
| 形 | 圆润、饱满、没有尖角；比例略夸张（头大身小、把手粗）；轮廓能一笔画出来 |
| 色 | 用 app 自己的这几个颜色和它们的深浅：橙 `#f79433` · 蓝 `#4db8ef` · 绿 `#6cc24a` · 红 `#f2706e` · 黄 `#f5c243` · 紫 `#b98cf0` · 青 `#45c4a8` · 粉 `#ef85b0`。每张 2 到 3 个主色，不要渐变 |
| 线 | 要么统一有一圈深色描边（约 3 % 画幅粗），要么统一没有。**别混** |
| 光 | 光从左上来，一层平涂的暗面 + 一小点高光，就够。不画投影（圆盘已经有阴影） |
| 视角 | 正面或四分之三，略俯视。61 张同一个视角 |
| 底 | 透明。不画背景、不画地面 |
| 缩小测试 | 缩到 40 px 还认得出是什么。认不出的减细节，不加 |

**先画三张试风格，再批量**：一枚字形（M1 博物馆修复师）、一枚徽章（夜猫子）、app 图标。放进对应目录、模拟器里看一眼，风格对了再画剩下的。三张定下来的东西就是这一套的样板。

## 3. 徽章 · 51 枚 🟢 可换

一枚章 = 一块带颜色的圆盘 + 上面一枚图形 + 底下名字。圆盘和名字是代码画的，**要画的只是圆盘上那枚图形**。徽章**只奖励过程**（画了多久、换了几种颜色、擦了多少），不奖励画得好不好，这是底线，图形上别出现「棒」「第一」这类意思。

**尺寸与格式**

| 项 | 要求 |
| --- | --- |
| 像素 | **186 × 186**，PNG，透明底 |
| 构图 | 圆形构图，主体占 70 %。圆盘会变成白到浅组色的底、组色留在边圈，所以插画自己要有颜色，别画成白色 |
| 文件名 | `static/art/badges/<徽章名>.png`，名字就是表里加粗的那个（例：`badges/夜猫子.png`）。放进去就生效，没放的仍用线稿 |

**显示位置与大小**：徽章墙和结算页，圆盘 62 × 62 CSS px（2× 屏 124 × 124），图形 30 px；点一枚才浮出说明。墙尾永远有一枚「?」（更多等你发现），**不报剩多少**。
