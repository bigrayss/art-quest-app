### 硬规格 · 四条都要满足

这四条是写死在代码里的（`spec`），四张现有图都照它拍的。**差一条，五张平行卷就不等价。**

| 规格 | 值 |
| --- | --- |
| 物体数 | **正好 4 个**。不多不少，也不要同一个物体出现两次 |
| 遮挡 | **正好 2 处**，而且要**一眼看得出**，不能只是边缘碰到 |
| 大小 | 四个物体之间有**明显**的大小差 |
| 纵深 | 分前后两排，不要四个并排站成一行 |

### 画什么

**四个物体**：相机、笔筒、折叠尺、橘子。

**摆法**（按这个摆，两处遮挡就自然出来了）：

| 物体 | 位置 | 大小 |
| --- | --- | --- |
| 相机 | 后排，偏左 | 最大 |
| 笔筒 | 后排，偏右，里面插着几支笔和一把剪刀 | 第二大 |
| 折叠尺 | 前排右侧，斜搭着，**一端压在笔筒底部前面** ← 遮挡 1 | 中等，横向长 |
| 橘子 | 前排中间偏左，**挡住相机机身的下缘** ← 遮挡 2 | 最小 |

**桌面和背景**：浅色木桌 + 素色浅墙。不要花纹、不要桌布、不要其他杂物。

**光**：从左上来，柔和，物体右下方有淡投影。

### 风格

和另外四张一套：**半写实的三维渲染感**，边缘干净，颜色明快不刺眼。参考数值 —— 现有四张的平均饱和度 0.40 到 0.46，亮度 0.73 到 0.83，新图落在这个区间里。
