## 一、入口与内容边界

年龄是入口路由，不是能力分数，也不等于已知的在读年级。年龄段的非重叠边界是本项目选择：6—7、8—10、11—12、13—14、15—16岁。课程参照按学段保存；超出范围或未提供年龄时，不静默分配任务。每个年龄段的候选和顺序固定，刷新不重新生成。语言只改变文案，不改变材料和任务条件。

这是25道首访替换任务，不是对旧M1—M9所有题目的重建，也不声称覆盖完整美术课程。五类为：观察、表达、图形片段、物品改造、视觉设计。当前不强制多张草图、可移动起始对象或限时阶段；多样化构想和已有作品改进留作独立扩展，不把图形片段或物品改造冒充它们。所有任务均为研究性改编，不是教材或PISA原题。 [ECD04; PISA23; URBAN05]

“冻结”指内容与材料版本固定，不表示教师审核、儿童预试或心理测量验证已完成。本包不虚构这些记录。课程与原始测评只提供设计依据；年龄与复杂度安排是待实证检验的项目设计。

## 三、所有任务共用的实施与完成后配置

- 学生只看到任务名称、题面、必要条件及主动打开的提示；后面的研究属性不作为儿童阅读负担。题面和必要条件相同，不在研究分析时补加隐藏要求。
- 全部任务从空白画布开始，提交一幅作品。参考图在参考区常显，不自动粘贴到学生作品；片段任务也采用参考区转抄，不依赖图层锁定或导入功能。
- 建议画布导出比例4:3。参考PNG统一1600×1200，以contain完整显示；不得用cover裁掉叶柄、车轮、笔筒底部等结构。已有画布尺寸不同时保留原比例并记录实际条件，不假称等值。
- 没有60秒阶段，没有硬限时、倒计时或速度分。可记录实际时间、暂停和帮助，但日志缺失不补成0。
- 提示是预先固定、按需显示的过程支持，不能产生新的必须条件。保存提示ID和显示事件；看过提示不等于没独立思考，也不能当作未受帮助数据。
- 所有任务允许单色，不要求写字。题目要求的图形、关系或功能才属于任务内容条件；颜色丰富度和文字长度不是通用完成门槛。
- 提交时先保存原图、任务快照和材料版本，再展示完成信息。学生可跳过“喜欢程度”“感觉难度”和每题的简短反思。系统反馈未到达时，显示已保存，不阻止结束。
- 作品评分继续使用你们已有模块。传入真实作品及需要的任务背景；九维关联不是分数、不是权重，也不自动改变原rubric。保留全局作品评分与任务内容分析的分离。
- 正式反馈只引用图中可见证据，先鼓励，建议最多一条，不引入额外要求。未知意图不编造，不从一幅画或一次选择直接生成稳定弱项。
- 首访默认不开启额外修改轮。现有产品若开启一次可选修改，应另存首稿、反馈和修改稿，并标为受帮助条件；不能覆盖首稿或混入无帮助表现。

### B1_OB_01 · 两片叶子

**年龄与类型**：6—7岁 / 观察与表现

**选题卡摘要**：看看两片叶子有什么不同。

**学生题面（常显）**：看看图里的两片叶子，把它们都画下来。让人能看出哪片宽、哪片长，再画上你看到的叶柄和叶脉。只画线条也可以。

**必要条件（与题面一致）**：画出参考图中的两片叶子；表现外形差别，并加入看到的叶柄和叶脉。

**可选提示**：H1: 先看叶子的外边，再看里面的线。 / H2: 可以把两片叶子画得大一些。

**自由空间**：线稿或上色都可以；大小、位置可自行安排，不要求每条叶脉完全相同。

**材料与使用**：[独立参考PNG](../assets/B1_OB_ref.png)。参考图：可随时查看，按完整比例显示。

**学习方向**：比较自然对象的外形与局部特征。

**复杂度描述（非实测难度）**：两个分离对象；没有遮挡要求；图像而非实物观察。

**九维关联（任务属性，不是评分）**

- 关注 · 写实表现 (`realism`)：共同参考允许比较外形与可见特征，不等于真实植物写生的全部能力。
- 关注 · 线条组合 (`line_combination`)：任务明确要求表现外边缘与叶脉之间的不同线条。
- 探索性 · 画面组织 (`picture_organization`)：两片叶子的安排可观察，但没有规定固定位置。
- 探索性 · 色彩丰富度 (`color_richness`)：只有学生主动用色时才可能出现相关信息。

**任务内容分析**：观察外形是否有区别、叶柄如何连接、叶脉如何分布；记录学生使用的表现方式，不要求复制插画笔触。

**不能直接推断**：不得因只用一种颜色判定本题失败；从插画临绘中不能推断真实植物知识。

**完成后可选反思**：你觉得这两片叶子哪里最不一样？

**提交和完成后配置**：保存一幅首稿；共用first_visit_common_v1；喜欢程度和感觉难度各一题可跳过；反思可跳过；不因反馈未完成而阻止退出。

**来源定位**：[C22], [YIN22] · 第一学段：表达自己的感受、改进生活用品、参与造型游戏活动

**明确的改编内容**：自然观察方向来自课程；两片叶子、宽长对照和本张插画均由本项目设置，不是教材原图。

### B1_ST_01 · 一起玩

**年龄与类型**：6—7岁 / 个人表达与叙事

**选题卡摘要**：画你喜欢的一起玩的时刻。

**学生题面（常显）**：画一件你和别人一起玩的事，也可以画你想象中的游戏。让人看出谁在玩、在做什么。只画一幅，不用写故事。

**必要条件（与题面一致）**：用一幅画表现一起玩的活动；让人物和主要动作在画面中出现。

**可选提示**：H1: 先想好最想画的那个动作。 / H2: 人物可以画得简单，重要的是看出在做什么。

**自由空间**：可以画真人、动物或想象角色；不用画真实姓名或学校。颜色和背景自由。

**材料与使用**：没有参考成品，从空白画布开始。

**学习方向**：用形象和动作表达一个生活或想象情境。

**复杂度描述（非实测难度）**：一个活动、单幅叙事；不要求连环画或准确人体比例。

**九维关联（任务属性，不是评分）**

- 关注 · 画面组织 (`picture_organization`)：人物和主要动作需要组织在同一情境中。
- 探索性 · 想象 (`imagination`)：可以出现想象游戏，但真实经历同样符合任务。
- 探索性 · 线条组合 (`line_combination`)：动作和形象可能通过线条呈现，技法不限。
- 探索性 · 色彩对比 (`color_contrast`)：用色不是必要条件。

**任务内容分析**：结合画面和自愿说明理解活动；关注人物之间是否有可辨识的活动联系。

**不能直接推断**：不依据游戏内容推断社交能力、家庭情况或心理状态；真实题材不比幻想题材低级。

**完成后可选反思**：你最想让别人看见谁在做什么？

**提交和完成后配置**：保存一幅首稿；共用first_visit_common_v1；喜欢程度和感觉难度各一题可跳过；反思可跳过；不因反馈未完成而阻止退出。

**来源定位**：[C22], [YIN22] · 第一学段：表达自己的感受、改进生活用品、参与造型游戏活动

**明确的改编内容**：借鉴课程的生活感受表达；共同游戏、单幅产出和无文字要求均为项目设计。

### B1_FG_01 · 一条线变什么

**年龄与类型**：6—7岁 / 图形片段创作

**选题卡摘要**：从一段弯线开始，画出自己的想法。

**学生题面（常显）**：看参考图里的那段弯线，把它画进你的画里，再添上自己的内容，让它变成你想到的东西。线可以转方向或变大变小，但要让人找得到原来的弯线。

**必要条件（与题面一致）**：使用参考图中的一段弯线发展一幅画；让原来的弯线仍能被找到。

**可选提示**：H1: 换个方向看看这段线。 / H2: 不必猜一个正确答案。

**自由空间**：画什么由你决定；可以移动、转动或缩放弯线；不要求精确临摹。

**材料与使用**：[独立参考PNG](../assets/B1_FG_ref.png)；[可编辑SVG](../assets/B1_FG_ref.svg)。参考图：可随时查看，按完整比例显示。 所有片段为本包原创；照参考转抄到空白画布，不复制原TCT-DP题纸。

**学习方向**：从模糊图形刺激发展个人构想。

**复杂度描述（非实测难度）**：一个片段；单幅画；不要求限时、原测验边框或原量表。

**九维关联（任务属性，不是评分）**

- 关注 · 想象 (`imagination`)：任务要求从未完成的线条提出一个视觉构想。
- 探索性 · 变形 (`deformation`)：学生可能改变或延展形状，也可能保留简单形象。
- 探索性 · 画面组织 (`picture_organization`)：如果构想包含多个元素，可观察它们的组织。

**任务内容分析**：记录原片段如何被纳入画面、增添内容如何形成想法；片段使用是任务内容记录，不另加分。

**不能直接推断**：不是TCT-DP或TTCT原题；转抄线条存在额外操作负担，不与原测验常模比较。

**完成后可选反思**：那段弯线在你的画里变成了什么？

**提交和完成后配置**：保存一幅首稿；共用first_visit_common_v1；喜欢程度和感觉难度各一题可跳过；反思可跳过；不因反馈未完成而阻止退出。

**来源定位**：[C22], [YIN22], [URBAN05] · 第一学段：表达自己的感受、改进生活用品、参与造型游戏活动

**明确的改编内容**：仅借鉴Urban（2005）第273页的图形片段创作范式；本包使用一段原创弯线、参考区呈现和自由手绘。

### B2_OB_01 · 苹果和两本书

**年龄与类型**：8—10岁 / 观察与表现

**选题卡摘要**：画出三件物品和它们的前后关系。

**学生题面（常显）**：看参考图，画出苹果和两本书，保留它们的大致位置。注意苹果挡住书的地方，让人能看出谁在前面。可以只用线条。

**必要条件（与题面一致）**：画出苹果和两本书；保留大致位置并表现苹果在书前面。

**可选提示**：H1: 先看看哪条边被前面的物品挡住了。 / H2: 不用把参考图的颜色和阴影一模一样地画下来。

**自由空间**：线稿或上色均可；整体可以放大或缩小；不要求精确临摹纹理。

**材料与使用**：[独立参考PNG](../assets/B2_OB_ref.png)；[可编辑SVG](../assets/B2_OB_ref.svg)。参考图：可随时查看，按完整比例显示。

**学习方向**：在共同参考下观察和表现物体间的空间联系。

**复杂度描述（非实测难度）**：三个对象、一项明确前后关系；复杂度为设计描述，不是实测难度。

**可选提示**：H1: 先想一个最能代表你的东西。 / H2: 标志缩小了也要认得出。

**自由空间**：图形、颜色、是否有字都自由；不要求画自己的脸或真名。

**材料与使用**：没有参考成品，从空白画布开始。

**学习方向**：用一个图形表达身份与用途。

**复杂度描述（非实测难度）**：一个用途、一幅标志；不要求文字。

**九维关联（任务属性，不是评分）**

- 关注 · 画面组织 (`picture_organization`)：图形要作为一个整体服务标志的用途。
- 探索性 · 想象 (`imagination`)：个人化符号可能体现新构想，常见图形也可合理完成。
- 探索性 · 色彩对比 (`color_contrast`)：使用颜色时可观察对比，不要求多色。

**任务内容分析**：记录图形与「自己 / 画廊」的联系；不评价像不像本人。

**不能直接推断**：不从标志推断性格；不要求写字。

**完成后可选反思**：别人看到这个标志会想到你的什么？

**提交和完成后配置**：保存一幅首稿；共用first_visit_common_v1；喜欢程度和感觉难度各一题可跳过；反思可跳过；不因反馈未完成而阻止退出。

**来源定位**：[C20] · 设计模块；[PISA23]；本项目的画廊功能

**明确的改编内容**：和 B2_DS「图书角标志」同一操作，用途换成本 app 里的个人画廊。
