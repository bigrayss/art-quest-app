# 任务库 v2.2 · 双锚定题对齐版 · 100 行

**2026-10-01 · 基于 v2.1 对齐修改；每个家族固定 2 道共通锚定题 + 小学 3 道独立题 + 初中 3 道独立题。**

10 个家族；小学版 5 道、初中版 5 道。每个家族的前 2 道为两版完全相同的共通锚定题，后 3 道分别为小学/初中独立题。表格仍有 100 行，但实际为 80 个独立题面：20 道共通题各重复在两版 + 60 道年龄独立题。

- **小学版**（简单版）：题目 ≤ 8 字，说明一句 ≤ 25 字，一个具体画面钩子，不出现「用颜色、空间和构图表达」这类成人话。
- **初中版**（完整版）：题目 ≤ 10 字，说明 ≤ 35 字，可以带一点设定和悬念。
- **共通锚定题规则**：每个家族 `S1 = F1`、`S2 = F2`，题目、说明、提示、素材完全一致，用于跨年龄直接比较；`S3–S5` 与 `F3–F5` 各自独立，用于年龄适配和保持趣味。
- 题目里不出现任何品牌和具体作品名。
- 「素材」一列：有参考图的家族标明用现有哪张图，「新图」= 要美术另画。

**选题规则（建议）**：普通模式仍从对应年龄版的 5 道题里抽取未做过的题；研究 protocol 若要比较小学与初中，优先固定两道共通锚定题（S1/F1、S2/F2），再从各自 3 道独立题里抽取。这样既有直接可比数据，也保留年龄适配。

> **v2.2 调整原则**：共通题必须真正相同，不做“同主题但不同难度”的伪重复；年龄差异放在各自 3 道独立题里。整体仍遵循：降低理解负担，不降低创造空间；提示给思考方向，不直接给画法答案。
