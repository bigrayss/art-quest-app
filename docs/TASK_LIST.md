# 任务清单（给老师看的版本）

app 里孩子能抽到的全部 **75 个任务**，按 10 个家族分。每个任务写了孩子看到的原话、提示、参考图、时限、工具限制和它主要考察的维度。**编号可以直接拿来指**：`4.7` 就是第 4 家族第 7 个任务。

> 由 `tools/gen_task_list.py` 从代码里生成，文字和 app 里的一字不差。**别手改这个文件**——意见写在别处（邮件、批注、或者直接写在最后一列复制走），我改进代码后重跑一次它就更新。

## 怎么提意见

对着编号说就行，比如「4.7 的指令改成……」「2.3 的提示太抽象」「M6 时限太短」。能改的东西：

- **标题、指令原话、提示语**：想怎么说就写出来，我照抄进去。
- **时限、允许的工具、参考图开不开**：家族级的设置，说清楚哪个家族。
- **一个任务主要考察哪几个维度**：见每节的「主要考察」。九个维度**每幅画都评**，「主要考察」只是说这个任务额外想看的。
- **增删任务、换参考图的内容**：也可以，写清楚要什么。

有两样请先商量再改：任务的 **id**（它是所有数据表的外键，改了历史数据就对不上）；M3 的碎片（程序生成的，前后端要逐像素对上，不能换成图片）。

## 九个维度

| 维度 | 看的是什么 |
| --- | --- |
| **写实** | 物体、比例、空间关系是否接近真实观察 |
| **变形** | 是否有意识地夸张、扭曲或简化形体来表达 |
| **想象** | 内容、情境、设定的新颖与独特程度 |
| **色彩丰富** | 颜色种类、层次与变化 |
| **色彩对比** | 明暗、冷暖、互补等对比的运用 |
| **线条组合** | 线条之间的组织、疏密与节奏 |
| **线条质感** | 线条的力度、粗细变化与肌理 |
| **画面组织** | 构图、主次、平衡与视线引导 |
| **转化** | 把熟悉事物转化为新形象、新功能或新故事的程度 |
