# 要画的三张参考图

**2026-10-02 · 任务库 v2.2。** 格式照 `docs/ART_LIST.md` 第 1 节。画完放进对应目录就生效，不用改代码。

## 通用要求（三张都一样）

| 项 | 要求 |
| --- | --- |
| 像素 | **2048 × 1408**（宽 × 高，16:11，和画布 1024 × 704 同比例） |
| 格式 | 场景用 **JPG**（质量 85 以上）；物体用 **PNG**，纯白底 `#FFFFFF`，**不要透明** |
| 安全区 | 重要内容放在**中间 60% 的高度里**。创作屏右栏的缩略图是 2:1 的横条，上下各切掉 20% |
| 色彩 | sRGB |
| 禁止 | 任何文字、商标、真人的脸；血腥、凌乱、吓人的暗示 |
| 来源 | 自己拍 / 自己画 / CC0。它们会随 app 发布 |
| 显示 | 缩略图约 512 × 256 px；点开全屏最大约 2000 × 1200 px，可两指放大到 4 倍看细节 |

## 1. `m4_bicycle` ⚠️ 试点前必须补

| 项 | 内容 |
| --- | --- |
| **id** | `m4_bicycle` |
| **文件** | `static/refs/m4/m4_bicycle.png` |
| **格式** | PNG，**纯白底** `#FFFFFF`，2048 × 1408 |
| **给哪道题** | M4_J5 初中「自行车机甲」 |
| **孩子看到的题** | 把自行车改成一台机甲。它能做什么？ |
| **提示** | 自行车哪些部分可以变成机甲的一部分？ |
| **怎么显示** | 默认收起，孩子点「看看参考图」才展开。**现在点开是空的** |

**这张图要有什么**

一辆普通自行车，整车完整不出框，占画面高度约 70%，四分之三侧视角（不是正侧面，要能看出车身的厚度）。

必须看得清的五处，孩子要把它们当成机甲的关节：

| 部位 | 为什么要清楚 |
| --- | --- |
| 车架三角 | 机甲的躯干 |
| 链条和齿盘 | 最容易想成关节、传动 |
| 两个轮子 | 可以变成脚、履带、推进器 |
| 车把 | 变成手臂或头 |
| 脚踏和曲柄 | 变成膝关节 |

普通的城市自行车或山地车都行，不要儿童车、不要折叠车（结构太简化，孩子没东西可改）。不要人骑在上面。不要背景、不要地面阴影。

**风格**：照同目录另外六张来（雨伞、背包、椅子、茶壶、时钟、鞋子）。那六张是写实感的插画，纯白底，光从左上来。

## 2. `m1_scene_e` 建议补

| 项 | 内容 |
| --- | --- |
| **id** | `m1_scene_e` |
| **文件** | `static/refs/m1/m1_scene_e.jpg` |
| **格式** | JPG，2048 × 1408 |
| **给哪两道题** | M1_E5 小学「拼图的最后一块」· M1_J5 初中「被删的画」 |
| **孩子看到的题** | 小学：拼图少了一大块。照着这张图把它补全。<br>初中：博物馆的画被删掉了一半。照着原图把它复原。 |
| **怎么显示** | 一进创作屏就在右栏显示，一直看得到 |
| **补它干什么** | 这两道题现在用的是 `m1_scene_a`，和「破掉的照片」撞了。一个孩子在这个家族做两道就会看到同一张图两次 |

**这张图要有什么**

一个有结构的场景，**6 到 8 个一眼能叫出名字的物体**，前中后三层清楚，物体之间有明确的左右和前后关系。白天，光线均匀，没有人。

**复杂度要和另外四张对齐**：物体数、遮挡处数、大小差异都对得上。这五张是平行卷，孩子做哪一道难度都该一样。

**题材避开已有的四张**：

| 已有 | 画的是 |
| --- | --- |
| `m1_scene_a` | 客厅一角：沙发、茶几、书架、台灯、盆栽、窗、猫 |
| `m1_scene_b` | 野外营地：帐篷、背包、篝火、树桩、溪流、远山 |
| `m1_scene_c` | 书桌一角：台灯、地图、放大镜、书、椅子、挂钟、软木板 |
| `m1_scene_d` | 公园：长椅、滑梯、秋千、路灯、树、花 |

**建议题材**：一间教室、一个厨房、一个车站月台。三个都是孩子熟悉、物体边界清楚的场景。

**物体要边界清楚，别互相糊成一团** —— 孩子评的是结构和位置，糊在一起他就画不出「谁在哪」。

**风格**：照另外四张来。写实感的插画，不是照片，颜色明快。

## 3. `m2_scene_e` 建议补

| 项 | 内容 |
| --- | --- |
| **id** | `m2_scene_e` |
| **文件** | `static/refs/m2/m2_scene_e.jpg` |
| **格式** | JPG，2048 × 1408 |
| **给哪两道题** | M2_E5 小学「侦探的笔记」· M2_J5 初中「博物馆藏品」 |
| **孩子看到的题** | 小学：你是小侦探。把现场的每样东西画进笔记。<br>初中：这组藏品要登记。画一张能看出大小和前后的图。 |
| **怎么显示** | 一进创作屏就在右栏显示，一直看得到 |
| **补它干什么** | 这两道题现在用的是 `m2_scene_a`，和「外星观察」撞了 |

**这张图要有什么 —— 这条是硬规格，写死在代码里**

| 规格 | 值 |
| --- | --- |
| 物体数 | **正好 4 个** |
| 遮挡 | **正好 2 处**，而且要**一眼看得出**，不能只是边缘碰到 |
| 大小 | 四个物体之间有**明显**的大小差 |
| 纵深 | 有前后距离，不能四个并排站一行 |
| 背景 | 素色桌面 + 素色背景，不要花纹 |

代码里的字段就是 `{"objects": 4, "overlaps": 2, "size_difference": true, "depth": true}`。四张现有图都照它拍的。**新图差一条，五张平行卷就不等价了。**

**题材避开已有的四张**：

| 已有 | 四个物体 |
| --- | --- |
| `m2_scene_a` | 绿植、玩具机器人、星星图案的盒子、足球 |
| `m2_scene_b` | 蓝色水壶、苹果、绿色书本、红色玩具车 |
| `m2_scene_c` | 贝壳、木箱、提灯、绳圈 |
| `m2_scene_d` | 积木塔、马克杯、泰迪熊、骰子 |

**建议题材**：相机 + 笔筒 + 折叠尺 + 橘子。相机最大放中间偏后，笔筒挡住相机一角，折叠尺斜搭在笔筒上（第二处遮挡），橘子最小放最前面。

**风格**：照另外四张来。木桌面、浅色墙、光从左上来、有柔和投影。
