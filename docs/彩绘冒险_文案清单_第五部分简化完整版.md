## 回写与核对

本节为清单使用说明，不是面向孩子的界面文案。

### 按原键回写

static/lang/en.js 的键是原中文。不能只改英文或只换语言包中的键，还需同步核对界面调用。附带的 JSON 保留每个编号的原文与新版，供逐条对应；不是可直接执行的语言包。

### 固定名称与片段

徽章名称、评分维度名称和任务 id 未改。U390、U509–U512、F19–F20、A19–A27 等片段或空值须按原有拼接和调用方式处理，不单独当作完整提示使用。

### 源清单未交代的部分

U377–U380 同时出现“完成后修改过一次”和“未完成”，原清单没有说明后者对应哪个阶段，本稿保留该组合并标记核对。U477／B21 没有给出粗细差值的单位，U489／B33 没有给出清晨时段的精确边界，本稿均未补写。U234 等“相册”表述仍按原清单保留，需由实际保存路径确认。

### 研究版本

80 道任务已提供润色后的中英文说明，不能直接标作原 v2.2。问卷及自评文字的修改也应随采用版本记录；本稿不变更题目数量、量表选项顺序或任务的硬性条件。
